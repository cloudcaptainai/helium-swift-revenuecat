# helium-swift-revenuecat

RevenueCat integration for the Helium iOS SDK.

## Installation

Add both packages to your project via Swift Package Manager:

```swift
.package(url: "https://github.com/cloudcaptainai/helium-swift", from: "4.12.0"),
.package(url: "https://github.com/cloudcaptainai/helium-swift-revenuecat", from: "1.1.0")
```

Then import both:

```swift
import Helium
import HeliumRevenueCat
```

## How to Integrate

Follow our [official documentation here](https://docs.tryhelium.com/sdk/quickstart-ios) to integrate Helium into your iOS app!
