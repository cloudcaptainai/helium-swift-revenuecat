# helium-swift-revenuecat

RevenueCat integration for the Helium iOS SDK.

## Installation

Add this package to your project via Swift Package Manager:

```swift
.package(url: "https://github.com/cloudcaptainai/helium-swift-revenuecat", from: "1.0.0")
```

## How to Integrate

Follow our [official documentation here](https://docs.tryhelium.com/sdk/quickstart-ios) to integrate Helium into your iOS app!
